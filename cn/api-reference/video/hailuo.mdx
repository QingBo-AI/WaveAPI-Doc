MiniMax 海螺（Hailuo）视频系列。本页覆盖 `minimax-hailuo-02`、`minimax-hailuo-2.3` 和 `minimax-hailuo-2.3-fast`：三个模型走同一个任务接口，都只有 `generate` 一个动作，从文字或首帧图片生成一段固定时长的视频，换档只改 `model`。需要参考视频、参考音频或原生音轨时用 [MiniMax H3](/cn/api-reference/video/minimax-h3)。

## 快速开始

<CodeGroup>

```bash 文生视频
curl -X POST https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: hailuo-demo-001" \
  -d '{
    "model": "minimax-hailuo-2.3",
    "action": "generate",
    "prompt": "山间雾气缓缓散开，晨光落在古寺屋檐上，镜头缓慢推近",
    "duration": 6,
    "resolution": "1080p"
  }'
```

```bash 首帧生视频
curl -X POST https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-hailuo-02",
    "action": "generate",
    "prompt": "人物缓缓抬头，风吹动头发",
    "first_frame_image": "https://cdn.example.com/portrait.jpg",
    "duration": 10,
    "resolution": "768p"
  }'
```

```bash 首尾帧
curl -X POST https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-hailuo-02",
    "action": "generate",
    "prompt": "从白天过渡到夜晚，灯光逐盏亮起",
    "first_frame_image": "https://cdn.example.com/day.jpg",
    "last_frame_image": "https://cdn.example.com/night.jpg",
    "duration": 10,
    "resolution": "768p"
  }'
```

```bash 加速档
curl -X POST https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-hailuo-2.3-fast",
    "action": "generate",
    "prompt": "城市夜景，霓虹灯沿街闪烁，镜头向右平移",
    "first_frame_image": "https://cdn.example.com/city-night.jpg",
    "duration": 6,
    "resolution": "768p",
    "prompt_optimizer": true
  }'
```

</CodeGroup>

提交成功后返回 `task_id`。用 [`GET /v1/tasks/{task_id}`](/cn/api-reference/task/status) 查询结果，也可以用 [`Prefer: wait`](/cn/api-reference/task/submit#请求内等待prefer-wait) 在一次调用里等待，或配置 Webhook。

## 请求参数

<ParamField body="model" type="string" required>
  三选一：`minimax-hailuo-02`、`minimax-hailuo-2.3` 或 `minimax-hailuo-2.3-fast`。
</ParamField>

<ParamField body="action" type="string" default="generate">
  `generate` 是本页三个模型唯一的动作。生成模式不由 `action` 区分：只给 `prompt` 是文生视频，带 `first_frame_image` 是首帧生视频，首帧加 `last_frame_image` 是首尾帧。
</ParamField>

<ParamField body="prompt" type="string" required>
  视频描述：场景、主体、动作、风格。`minimax-hailuo-2.3` 与 `minimax-hailuo-2.3-fast` 还支持在提示词里嵌入运镜标签，见[使用示例](#使用示例)。
</ParamField>

<ParamField body="duration" type="integer">
  视频时长（秒）。

  - `minimax-hailuo-02`：`5` 或 `10`，默认 `5`
  - `minimax-hailuo-2.3` 与 `minimax-hailuo-2.3-fast`：`6` 或 `10`，默认 `6`
</ParamField>

<ParamField body="resolution" type="string">
  输出分辨率。

  - `minimax-hailuo-02`：`512p`、`768p` 或 `1080p`，默认 `768p`
  - `minimax-hailuo-2.3` 与 `minimax-hailuo-2.3-fast`：`768p` 或 `1080p`，默认 `768p`
</ParamField>

<ParamField body="first_frame_image" type="string">
  首帧图片 URL，作为视频的起始画面。`minimax-hailuo-2.3-fast` 必填。
</ParamField>

<ParamField body="last_frame_image" type="string">
  尾帧图片 URL，与 `first_frame_image` 配合做「从 A 变到 B」。只有 `minimax-hailuo-02` 支持。
</ParamField>

<ParamField body="prompt_optimizer" type="boolean" default="true">
  自动优化提示词。
</ParamField>

<ParamField body="fast_pretreatment" type="boolean" default="false">
  缩短提示词优化耗时，速度更快，优化效果可能略降。
</ParamField>

<ParamField body="watermark" type="boolean" default="false">
  输出添加水印。
</ParamField>

通用的 `callback_url`、`callback_events`、`Prefer: wait`、`Idempotency-Key` 和费用上限请求头见[提交任务](/cn/api-reference/task/submit)。

本页三个模型都不接受 `image_urls`、`video_urls`、`audio_urls`、`aspect_ratio`、`n`、`seed` 和 `negative_prompt`；`minimax-hailuo-2.3` 与 `minimax-hailuo-2.3-fast` 不接受 `last_frame_image`。以上之外的参数会返回 `400`，不计费。

## 限制

| 模型 | 条件 | 限制 |
|---|---|---|
| `minimax-hailuo-02` | 每次请求 | 每次任务只生成一个视频。 |
| `minimax-hailuo-02` | `resolution: "512p"` | 512p 只支持图生视频，需要提供首帧图片。 |
| `minimax-hailuo-02` | `resolution: "1080p"` | 1080p 仅支持 5 秒。 |
| `minimax-hailuo-02` | 传 `last_frame_image` | 尾帧必须与首帧一起提供。 |
| `minimax-hailuo-2.3` `minimax-hailuo-2.3-fast` | 每次请求 | 本模型一次任务只产出一个结果，不支持用 n 批量生成 |
| `minimax-hailuo-2.3` `minimax-hailuo-2.3-fast` | `resolution: "1080p"` | 1080p 只支持 6 秒 |
| `minimax-hailuo-2.3-fast` | 每次请求 | 必须提供 `first_frame_image` |

`minimax-hailuo-02` 每次请求最多接受 2 张图片，即首帧与尾帧各一张。

## 计费

按**分辨率 × 时长档的整片价**计费，不按秒：每个分辨率与时长的组合是一档固定价，提交前即可确定单次费用。

| 模型 ID | 计费档位 |
|---|---|
| `minimax-hailuo-02` | `512p` 5 秒 / 10 秒，`768p` 5 秒 / 10 秒，`1080p` 5 秒 |
| `minimax-hailuo-2.3` | `768p` 6 秒 / 10 秒，`1080p` 6 秒 |
| `minimax-hailuo-2.3-fast` | `768p` 6 秒 / 10 秒，`1080p` 6 秒 |

不传 `resolution` 或 `duration` 时按默认值（`768p`，5 秒或 6 秒）对应的档位计。`prompt_optimizer`、`fast_pretreatment`、`watermark` 和首帧 / 尾帧图片都不影响价格。

<Note>
各模型的单价见 `GET /v1/models` 返回的 `price_config`，或控制台「模型市场」。

看这一单实际花了多少：任务响应里的 `cost`（整数 quota，500,000 quota = 1 USD）。
</Note>

只有成功出片才计费。任务失败、取消，或没有返回可用视频时，全额退款。最终费用以任务响应里的 `cost` 为准，它是整数 quota 不是美元。

## 可用模型

| 模型 ID | 分辨率 | 时长（秒） | 模式 | 备注 |
|---|---|---|---|---|
| `minimax-hailuo-02` | `512p` `768p`（默认）`1080p` | 5（默认）/ 10 | 文生视频、首帧、首尾帧 | `512p` 需要首帧；`1080p` 仅 5 秒 |
| `minimax-hailuo-2.3` | `768p`（默认）`1080p` | 6（默认）/ 10 | 文生视频、首帧 | 支持运镜标签 |
| `minimax-hailuo-2.3-fast` | `768p`（默认）`1080p` | 6（默认）/ 10 | 首帧（必填） | 2.3 的加速档，单价更低 |

## 使用示例

`minimax-hailuo-2.3` 与 `minimax-hailuo-2.3-fast` 支持在 `prompt` 里用 `[标签]` 的写法指定镜头运动，标签用中文原文，可以和描述文字混排、也可以在一句里叠加多个：

| 类别 | 标签 |
|---|---|
| 平移 | `[左移]` `[右移]` |
| 升降 | `[上升]` `[下降]` |
| 推拉 | `[推进]` `[拉远]` |
| 摇镜 | `[左摇]` `[右摇]` `[上摇]` `[下摇]` |
| 变焦 | `[变焦推近]` `[变焦拉远]` |
| 其他 | `[晃动]` `[跟随]` `[固定]` |

```json 带运镜标签的请求体
{
  "model": "minimax-hailuo-2.3",
  "action": "generate",
  "prompt": "[推进] 古镇的青石板路，[变焦推近] 雨水从屋檐滴落",
  "duration": 6,
  "resolution": "1080p"
}
```
