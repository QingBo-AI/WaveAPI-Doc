`magi-2` 固定输出 1080p，支持 4–30 秒。选择 `action: "generate"`，用 `duration` 指定整数秒数。

```json
{
  "model": "magi-2",
  "action": "generate",
  "prompt": "雨滴落在深蓝釉面的陶瓷杯边缘，镜头缓慢靠近，背景只有轻微雨声。",
  "duration": 4,
  "resolution": "1080p",
  "aspect_ratio": "16:9",
  "generate_audio": true
}
```

| 模式 | 输入 |
|---|---|
| 文生视频 | 提供提示词和时长。可选画幅为 16:9、9:16、1:1、4:3、3:4、21:9 |
| 首尾帧 | 用 `first_frame_image` 和可选的 `last_frame_image`，或用 `image_urls` 按顺序传 1–2 张图。省略画幅或传 `auto` 时跟随首帧，图生模式的固定画幅范围为 16:9、9:16、1:1、4:3、3:4 |
| 多模态参考 | 传 `omni_reference_task_type: "reference"`，最多 10 张 `image_urls`、5 段 `video_urls` 和 5 段 `audio_urls`。视频和音频各自合计最多 30 秒，每段 2–30 秒 |

`generate_audio` 默认开启，可设为 `false`。成片按请求输出时长计费，单价 **$0.09 / 秒**。4 秒预扣 **$0.36**，音轨和参考素材均包含在时长价内。

提交后使用返回的任务 ID [查询状态](/cn/api-reference/task/status)。成功时从 `result.videos[0].url[]` 获取成片，实扣以任务的 `cost` 和 `billing_status` 为准。
