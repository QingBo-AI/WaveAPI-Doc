列出本账号未删除的素材，按创建时间倒序。

<RequestExample>
```bash cURL
curl "https://api.qingbo.ai/v1/assets?limit=20&offset=0" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.qingbo.ai/v1/assets",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    params={"limit": 20, "offset": 0}
)

for asset in response.json()["data"]:
    print(asset["id"], asset["status"])
```
</RequestExample>

## 鉴权

<ParamField header="Authorization" type="string" required>
  `Bearer YOUR_API_KEY`。API Key 的 quota 已用尽时也可调用。
</ParamField>

## 请求参数

<ParamField query="limit" type="integer" default="20">
  每页条数，取值 `1`–`100`。超出范围按 `20` 处理。
</ParamField>

<ParamField query="offset" type="integer" default="0">
  跳过条数。
</ParamField>

## 响应

<ResponseField name="object" type="string">
  固定为 `list`。
</ResponseField>

<ResponseField name="data" type="array">
  素材对象数组，字段见[查询素材](/cn/api-reference/assets/get)。条数小于 `limit` 即为最后一页。
</ResponseField>

## 错误码

| HTTP | `code` | 说明 |
|---|---|---|
| 401 | — | API Key 缺失或无效 |
| 500 | `asset_store_error` | 素材记录读取失败，可重试 |
