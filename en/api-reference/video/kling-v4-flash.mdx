Model IDs: `kling-v4-flash`.

## Quick start

```bash
curl https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: kling-v4-flash-example-001" \
  -d '{
    "model": "kling-v4-flash",
    "action": "generate",
    "prompt": "Warm sunset caustics move across an amber glass orb resting in a shallow reflecting pool, subtle camera glide, no text.",
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 3
}'
```

Poll the original task with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status). Check both `status` and `billing_status`. Output URLs are in `result.videos[0].url[]`; download them before expiration. A client timeout does not justify a new submission.

## Accepted parameters

| Parameter | Range |
|---|---|
| `action` | `generate` |
| `duration` | 3–20 integer seconds; default 10 |
| `resolution` | 720p; default 720p |
| `aspect_ratio` | `16:9` / `9:16`; default 16:9 |
| Image input | `image_urls` or `first_frame_image`, up to 10 images |
| `watermark` | Default false |

This release exposes text/image generation. Video editing, video references and extension are not yet exposed. Kling first-frame requests omit the upstream aspect ratio; framing follows the image.

## Billing

Reserve and bill the requested output duration at **$0.0964287/second**, 720p. A 3-second quote is approximately **$0.289288**. Video-input modes are not exposed and their fees are not added to ordinary generation.
