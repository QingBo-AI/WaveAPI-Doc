The ByteDance Seedance video line: the two 1.0 tiers cover text-to-video and first/last-frame control, 1.5 Pro adds multi-image reference and native audio, the three 2.0 tiers widen references to images, video and audio, and 2.5 adds video editing and video extension on top. This page covers the seven available models. They share one task endpoint and one set of parameters, and differ in the resolutions, duration ranges and reference material each accepts — switching tiers means changing `model`.

<Note>
Seedance is the video line; the image models under the similar name are the [Seedream Series](/en/api-reference/image/seedream), with different parameters and different billing.
</Note>

## Quick start

<CodeGroup>

```bash Text to video
curl -X POST https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: seedance-demo-001" \
  -d '{
    "model": "seedance-2.0",
    "action": "generate",
    "prompt": "A kitten yawning at the camera, slow-motion close-up",
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'
```

```bash First and last frame
curl -X POST https://api.qingbo.ai/v1/tasks \

    "last_frame_image": "https://cdn.example.com/last.jpg",

  }'
```

</CodeGroup>

A successful submission returns a `task_id`. Retrieve the result with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status), wait inline with [`Prefer: wait`](/en/api-reference/task/submit#in-request-waiting-prefer-wait), or configure a webhook.

`edit` and `extend` take a **video URL**, not the previous `task_id`: run `generate` first, read the video address from `result.videos[].url` on the finished task, and pass it in `video_urls` on the next call. To continue the same shot instead, send `return_last_frame` on the earlier call and use the returned last frame as the next `first_frame_image`.

## Request parameters

<ParamField body="model" type="string" required>
  The model ID; see Available models for the values.
</ParamField>

<ParamField body="action" type="string" default="generate">
  - `generate`: generate a video, on every model
  - `edit`: edit a source video, `seedance-2.5` only
  - `extend`: extend a source video, `seedance-2.5` only

  Both `edit` and `extend` require `video_urls` and the `adaptive` aspect ratio.
</ParamField>

<ParamField body="prompt" type="string" required>
  The video description or editing instruction. On `seedance-2.0`, `seedance-2.0-fast` and `seedance-2.0-mini` the prompt is optional when reference material is present; everywhere else it is required.
</ParamField>

<ParamField body="duration" type="integer">
  Output length in seconds, an integer. The range depends on the model: `2`–`12` on `seedance-1.0-pro` and `seedance-1.0-pro-fast`, `4`–`12` on `seedance-1.5-pro`, `4`–`15` on the three 2.0 tiers, `4`–`30` on `seedance-2.5`.

  Special values on `seedance-2.5`:

  - `0` under `generate` or `extend`: the model picks the length (4–30 seconds), billed on the length actually generated
  - `0` under `edit`: the output keeps the source video's length
</ParamField>

<ParamField body="resolution" type="string">
  Output resolution; the tiers each model accepts are listed under Available models. Defaults to `1080p` on `seedance-1.0-pro` and `seedance-1.0-pro-fast`, and to `720p` on the other models.
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Frame ratio: `16:9`, `9:16`, `1:1`, `4:3`, `3:4` or `21:9`. The four 2.x models also accept `adaptive`, which follows the input material.

  Defaults to `adaptive` on `seedance-2.5` and to `16:9` on the other models. On 2.x, first-frame and first/last-frame jobs as well as `edit` and `extend` accept `adaptive` only.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Number of videos to generate. Value: `1`. Each task returns one video.
</ParamField>

<ParamField body="seed" type="integer">
  Random seed. The same request and seed produce similar results.
</ParamField>

<ParamField body="first_frame_image" type="string">
  First frame image URL. Supported on every model.
</ParamField>

<ParamField body="last_frame_image" type="string">
  Last frame image URL; must be sent together with `first_frame_image`. Not supported on `seedance-1.0-pro-fast`.
</ParamField>

<ParamField body="image_urls" type="string[]">
  Reference image URLs. Up to 2 on `seedance-1.5-pro`, 9 on the three 2.0 tiers and 30 on `seedance-2.5`; `seedance-1.0-pro` and `seedance-1.0-pro-fast` do not take this field. Reference images cannot be combined with a first or last frame; on `seedance-1.5-pro` and the three 2.0 tiers they cannot be combined with `image_with_roles`.
</ParamField>

<ParamField body="video_urls" type="string[]">
  Reference video URLs. Up to 3 clips totalling 2 to 15 seconds on the 2.0 tiers, and up to 10 clips totalling 2 to 30 seconds on `seedance-2.5`; the 1.0 and 1.5 models do not take this field. `edit` and `extend` on `seedance-2.5` use it for the source video.
</ParamField>

<ParamField body="audio_urls" type="string[]">
  Reference audio URLs. Up to 3 clips totalling 15 seconds on the 2.0 tiers, and up to 10 clips totalling 30 seconds (2 to 30 seconds each) on `seedance-2.5`; the 1.0 and 1.5 models do not take this field.
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  Whether to generate a video with sound. Supported on `seedance-1.5-pro` and the four 2.x models; `seedance-1.0-pro` and `seedance-1.0-pro-fast` do not support it.
</ParamField>

<ParamField body="watermark" type="boolean">
  Whether to watermark the output video. `seedance-2.5` only.
</ParamField>

<ParamField body="image_with_roles" type="object[]">
  Role-tagged images, merged with `first_frame_image` and `last_frame_image`. Each entry holds a `url` and a `role`; supported on every model. `role` values:

  - `seedance-1.0-pro`, `seedance-1.5-pro`: `first_frame` or `last_frame`, at most one each
  - `seedance-1.0-pro-fast`: `first_frame` only
  - The three 2.0 tiers and `seedance-2.5`: `first_frame`, `last_frame` or `reference_image`

  Cannot be combined with `image_urls` on `seedance-1.5-pro` and the three 2.0 tiers.
</ParamField>

<ParamField body="camerafixed" type="boolean" default="false">
  Keep the camera fixed. `generate` on `seedance-1.5-pro` only.
</ParamField>

<ParamField body="return_last_frame" type="boolean" default="false">
  Return the last frame for continuation. Supported on the four 2.x models.
</ParamField>

<ParamField body="tools" type="object[]">
  Tool list; currently only `[{"type": "web_search"}]`, which grounds generation on web information. Supported on the four 2.x models.
</ParamField>

<ParamField body="output_format" type="string" default="mp4">
  Output video container format, `mp4` or `mov`. `seedance-2.5` only.
</ParamField>

<ParamField body="omni_reference_task_type" type="string" default="auto">
  Reference-mode hint for `generate`, `auto` or `reference`. Sending `reference` validates the reference-to-video constraints at submit time: an invalid request returns `400` with no task created and nothing billed. `edit` and `extend` are derived from the action and need no hint. `seedance-2.5` only.
</ParamField>

### Asset references (`asset://`)

On `seedance-2.0`, `seedance-2.0-fast`, `seedance-2.0-mini` and `seedance-2.5`, media fields accept `asset://<asset ID>` to reference an asset uploaded to the [Asset library](/en/api-reference/assets/overview); assets and ordinary links can be mixed:

| Asset type | Fields |
|---|---|
| Image | `image_urls`, `first_frame_image`, `last_frame_image`, `image_with_roles[].url` |
| Video | `video_urls` |
| Audio | `audio_urls` |

Only active assets owned by your account can be referenced; an asset that does not exist, belongs to another account or is not active returns `400` and is not billed. Other models do not accept `asset://`.

See [Submit Task](/en/api-reference/task/submit) for `callback_url`, `callback_events`, `Prefer: wait`, `Idempotency-Key` and the maximum-cost header.

Any other parameter returns `400` and is not billed.

## Limits

- Each task returns one video.
- This model requires a prompt. (`seedance-1.0-pro`, `seedance-1.0-pro-fast`, `seedance-1.5-pro`, `seedance-2.5`)
- Text-only generation requires a prompt; prompt is optional when reference media is present. (`seedance-2.0`, `seedance-2.0-fast`, `seedance-2.0-mini`)
- generate/extend requires an explicit duration from 2 to 12 seconds. (`seedance-1.0-pro`, `seedance-1.0-pro-fast`)
- generate/extend requires an explicit duration from 4 to 12 seconds. (`seedance-1.5-pro`)
- generate/extend requires an explicit duration from 4 to 15 seconds. (`seedance-2.0`, `seedance-2.0-fast`, `seedance-2.0-mini`)
- generate/extend requires duration: 4 to 30 seconds, or 0 to let the model pick the length. (`seedance-2.5`)
- A last frame requires a first frame. (every model except `seedance-1.0-pro-fast`)
- First/last frames cannot be mixed with general image references.
- 2.x first-frame tasks require adaptive aspect ratio.
- 2.x first/last-frame tasks require adaptive aspect ratio.
- At most two reference images are accepted. (`seedance-1.5-pro`)
- Reference videos must be duration-readable HTTP(S) MP4/MOV/WebM or your own active asset:// video assets; total duration must be 2 to 15 seconds. (`seedance-2.0`, `seedance-2.0-fast`, `seedance-2.0-mini`)
- Reference videos must be duration-readable HTTP(S) MP4/MOV/WebM or your own active asset:// video assets; total duration must be 2 to 30 seconds. (`seedance-2.5`)
- Seedance 2.0 does not accept audio-only reference requests.
- image_with_roles cannot be combined with image_urls. (`seedance-1.5-pro`, `seedance-2.0`, `seedance-2.0-fast`, `seedance-2.0-mini`)
- Video edit requires a source video, adaptive aspect ratio, and source-length duration. (`seedance-2.5` · `edit`)
- The edit source video must be 4 to 30 seconds. (`seedance-2.5` · `edit`)
- Video extension requires a source video and adaptive aspect ratio. (`seedance-2.5` · `extend`)

| Item | 1.0 Pro / Pro Fast | 1.5 Pro | 2.0 / Fast / Mini | 2.5 |
|---|---|---|---|---|
| Reference images `image_urls` | Not supported | 2 | 9 | 30 |
| Reference videos `video_urls` | Not supported | Not supported | 3 clips, 2–15s total | 10 clips, 2–30s total |
| Reference audio `audio_urls` | Not supported | Not supported | 3 clips, 15s total | 10 clips, 30s total |
| Duration `duration` | 2–12s | 4–12s | 4–15s | 4–30s, or `0` for model-chosen |
| Excluded by a first/last frame | No reference material on this tier | `image_urls` | `image_urls` / `video_urls` / `audio_urls` | `image_urls` |

The upstream also classifies 2.5 sub-tasks from the prompt: write `edit` prompts as editing instructions (remove, replace, modify) and `extend` prompts as continuation instructions, matching the `action` you send.

## Pricing

Billing is **resolution tier × output seconds**. Within one model, higher resolutions cost more; at the same resolution, `seedance-2.0-mini` is the cheapest, `seedance-2.0-fast` sits in the middle and `seedance-2.0` is the most expensive.

With a reference video (`video_urls`, on the three 2.0 tiers and `seedance-2.5`), the charge is the sum of two parts:

- the **output seconds**, at the **reference-video tier** for that resolution
- the reference video's **input seconds**, at the **input-second** rate

| Model | Output seconds | Input seconds |
|---|---|---|
| The three 2.0 tiers | The requested `duration` | The reference video's actual length |
| `seedance-2.5` · `generate` / `extend` | The requested `duration`; with `0`, the length actually generated | The reference video's actual length, and no less than 0.75 × the output seconds (rounded up) |
| `seedance-2.5` · `edit` | The source video's length | The source video's length |

The reference video's length is read at submit time; when it cannot be read, the model's reference-video ceiling is used instead, and `asset://` assets use the length measured at upload. Reference images and reference audio carry no separate charge.

`seedance-1.5-pro` has its own audio tier, so `generate_audio` is billed at the audio tier for that resolution; on the other models audio does not change the tier.

`seedance-2.5` freezes quota at submission (at 30 seconds when `duration` is `0`) and settles on the actual result when the task completes, refunding the difference.

<Note>
Per-model rates are in `price_config` on `GET /v1/models`, and in the console's Model Market.

What a single call actually cost is the `cost` field on the task response — an integer quota at 500,000 quota = 1 USD.
</Note>

You are billed only for a delivered video. Failed and cancelled tasks, and upstream successes that carry no deliverable video, are refunded in full. The final charge is the `cost` field on the task response — an integer quota, not dollars.

## Response

```json Completed task
{
  "task_id": "task-wave1775285160b950328499",
  "model": "seedance-2.0",
  "action": "generate",
  "status": "completed",
  "progress": "100%",
  "created_at": 1775285160,
  "completed_at": 1775285300,
  "result": {
    "videos": [
      {
        "expires_at": 1775371560,
        "url": ["https://cdn.example.com/result.mp4"]
      }
    ]
  },
  "billing_status": "settled",
  "cost": 75000,
  "urls": {
    "get": "https://api.qingbo.ai/v1/tasks/task-wave1775285160b950328499",
    "cancel": "https://api.qingbo.ai/v1/tasks/task-wave1775285160b950328499/cancel"
  }
}
```

Generated videos are returned in `result.videos`; `url` is an array and `expires_at` is the link expiry in Unix seconds, so copy the file to your own storage before then. Tasks submitted with `return_last_frame` also carry the last-frame image in the result. See [Query Task Status](/en/api-reference/task/status) for the full field reference.

## Available models

| Model ID | Resolution | Duration (s) | Reference material | Actions |
|---|---|---|---|---|
| `seedance-1.0-pro` | `480p` / `720p` / `1080p` | 2–12 | First and last frame | `generate` |
| `seedance-1.0-pro-fast` | `480p` / `720p` / `1080p` | 2–12 | First frame | `generate` |
| `seedance-1.5-pro` | `480p` / `720p` / `1080p` | 4–12 | First/last frame, 2 images | `generate` |
| `seedance-2.0` | `480p` / `720p` / `1080p` / `4k` | 4–15 | First/last frame, 9 images, 3 videos, 3 audio | `generate` |
| `seedance-2.0-fast` | `480p` / `720p` | 4–15 | First/last frame, 9 images, 3 videos, 3 audio | `generate` |
