Model IDs: `gemini-omni-1.2-flash-rev`.

`-rev` identifies the **Economy** edition. Version 1.2 is independent and does not replace 1.1 or `omni-flash-ext`.

## Quick start

```bash
curl https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: gemini-omni-1.2-flash-example-001" \
  -d '{
    "model": "gemini-omni-1.2-flash-rev",
    "action": "generate",
    "prompt": "Warm sunset caustics move across an amber glass orb resting in a shallow reflecting pool, subtle camera glide, no text.",
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 3
}'
```

Poll the original task with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status). Check both `status` and `billing_status`. Output URLs are in `result.videos[0].url[]`; download them before expiration. A client timeout does not justify a new submission.

## Accepted parameters

| Parameter | Range |
|---|---|
| `action` | `generate` |
| `duration` | 3–15 integer seconds; default 10 |
| `resolution` | 360p / 720p / 1080p / 4k; default 720p |
| `aspect_ratio` | `16:9` / `9:16`; default 16:9 |
| Image input | `image_urls` or `first_frame_image`, up to 10 images |
| `watermark` | Default false |

This release exposes text/image generation. Video editing, video references and extension are not yet exposed.

## Billing

The official edition has not passed availability acceptance and is not exposed. Economy: **$0.018/s** at 360p, **$0.027/s** at 720p / 1080p, **$0.063/s** at 4K.
