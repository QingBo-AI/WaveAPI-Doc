Flare and Sunburst with six quality options, planning effort, masks and annotation editing, billed by actual tokens.

Model IDs: `gpt-image-2.6-flare` / `gpt-image-2.6-sunburst`.

## Quick start

```bash
curl -X POST https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: image26-demo-001" \
  -d '{
  "model": "gpt-image-2.6-flare",
  "action": "generate",
  "prompt": "A sculptural glass vase on ivory stone, soft side light, refined editorial photography",
  "resolution": "1k",
  "aspect_ratio": "4:5",
  "quality": "medium",
  "complexity": "high",
  "n": 1
}'
```

Read `task_id` after submission and poll `GET /v1/tasks/{task_id}`. Download files from `result.images[].url[]` on success. Continue polling the original task after a timeout; do not submit a duplicate.

## Parameters

| Parameter | Values and rules |
|---|---|
| `action` | generate for text generation; edit requires image_urls. |
| `prompt` | Required description or edit instruction. |
| `image_urls` | 1–16 publicly accessible reference images for editing. |
| `resolution` | 1k / 2k / 4k; defaults to 1k. |
| `aspect_ratio` | 1:1 / 3:2 / 2:3 / 4:3 / 3:4 / 5:4 / 4:5 / 16:9 / 9:16 / 2:1 / 1:2 / 21:9 / 9:21 / 3:1 / 1:3. Default: 1:1. |
| `quality` | low / medium / high / xhigh / max / auto; defaults to low. |
| `complexity` | low / medium / high, defaults to high. Planning effort is independent of quality and has no separate fee. |
| `n` | 1–4, defaults to 1. Reservation scales with image count. |
| `output_format` | png / jpeg / webp / gif. Default: png. |
| `mask_url` | Alpha PNG mask matching the first reference; transparent pixels mark the edit area. Requires image_urls. |
| `markup_url` | Transparent PNG annotation layer matching the first reference. edit only, requires references, mutually exclusive with mask_url. |
| `background` | auto / opaque / transparent. Transparent backgrounds require PNG or WebP. |
| `moderation` | auto / low; defaults to low. |
| `output_compression` | Integer 0–100 for JPEG/WebP only. |
| `safety_identifier` | Optional stable end-user identifier, up to 128 characters; use a hash. |

## GIF animation

Both official routes support `output_format: "gif"` for text generation. Defaults are 512×512, 9 frames and 200ms per frame. `n` counts animations, not frames.

| Parameter | GIF rules |
|---|---|
| `size` | Per-frame pixels: auto / 512x512 / 768x768. auto means 512x512. |
| `frame_count` | Integer 2–16, default 9. 768x768 supports at most 12 frames. |
| `frame_duration_ms` | Default 200, minimum 20, in multiples of 10. Does not change the price. |
| `quality` | low / medium / high; defaults to low. |
| `resolution` / `aspect_ratio` | Keep the defaults 1k / 1:1; size determines per-frame pixels. |
| `n` | 1–4 animations; reserve one complete sprite sheet per animation. |

```json
{
  "model": "gpt-image-2.6-flare",
  "action": "generate",
  "prompt": "An ivory paper lantern sways in a soft night breeze, warm amber light, deep navy background, seamless loop",
  "output_format": "gif",
  "size": "512x512",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "quality": "low",
  "n": 1
}
```

Poll the same task endpoint and download the GIF from `result.images[].url[]`. Reservation uses the full sprite-sheet output token tier plus prompt allowance for each animation. Settlement uses actual typed tokens within the hold and refunds the difference; it does not multiply a static-image price by frame count.

For example, 512x512 / 9 frames / low reserves 1172 output tokens ($0.031644), plus prompt allowance. A real receipt used 68 text input + 1172 image output tokens and settled at $0.03195. This is an example receipt; obtain a fresh quote before submission. 

## Billing

Charged by actual typed token usage, in USD per million tokens:

| Text input | Cached text | Image input | Cached image | Image output |
|---|---|---|---|---|
| 4.5 | 1.125 | 7.2 | 1.8 | 27 |

Quotes reserve prompt, reference and output usage. `quality: "auto"` reserves max; successful tasks settle actual usage within the hold. Version 2.6 low/medium usage differs from 2.5, so request a new quote. Safety rejections may charge processed input, with no charge for ungenerated output. Unconfirmed cost or usage remains billing_status pending until reconciliation.

## Limits

SVG and exact pixel sizes for static images are not exposed. GIF supports only the square frame sizes and qualities listed above. Reference editing, masks, annotations, compression and transparent backgrounds are unavailable for GIF.
