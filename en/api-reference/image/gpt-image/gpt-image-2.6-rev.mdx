Flare and Sunburst, fixed-price 1K / 2K / 4K images, reference editing and 1K text-to-GIF.

Model IDs: `gpt-image-2.6-flare-rev` / `gpt-image-2.6-sunburst-rev`.

## Quick start

```bash
curl -X POST https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: image26-rev-demo-001" \
  -d '{
  "model": "gpt-image-2.6-flare-rev",
  "action": "generate",
  "prompt": "A sculptural glass vase on ivory stone, soft side light, refined editorial photography",
  "resolution": "2k",
  "aspect_ratio": "4:5",
  "quality": "medium",
  "complexity": "high",
  "n": 1
}'
```

Read `task_id` after submission and poll `GET /v1/tasks/{task_id}`. Download files from `result.images[].url[]` on success. Continue polling the original task after a timeout; do not submit a duplicate.

## Parameters

| Parameter | Values and rules |
|---|---|
| `action` | generate for text generation; edit requires image_urls. |
| `prompt` | Required description or edit instruction. |
| `image_urls` | 1–16 publicly accessible reference images for editing. At 2K/4K use PNG/JPEG/WebP, not GIF/BMP. |
| `resolution` | 1k / 2k / 4k; defaults to 1k. GIF is limited to 1k. |
| `aspect_ratio` | auto / 1:1 / 16:9 / 9:16 / 4:3 / 3:4 / 3:2 / 2:3 / 5:4 / 4:5 / 21:9. GIF requires explicit auto. |
| `quality` | low / medium / high / xhigh / max / auto; defaults to low. |
| `complexity` | low / medium / high, defaults to high. Planning effort is independent of quality and has no separate fee. |
| `n` | Must be 1. |
| `output_format` | png / jpeg / webp / gif; defaults to png. GIF requires 1k generate without references. |

## Billing

Both variants use the same fixed per-image prices:

| Resolution | USD / image |
|---|---:|
| 1K | $0.0095625; approximately $0.009564 after billing-unit rounding |
| 2K | $0.03375 |
| 4K | $0.045 |

Quality, planning effort and references have no separate surcharge. The reservation and successful settlement use the same fixed price. Existing tasks retain their frozen tariff after a price update. Check final `billing_status` and refund records for failed tasks.

### Resolution and actual pixels

`4k` names the supplier's resolution tier, rather than a promise of a 4096-pixel edge for every aspect ratio:

| Aspect ratio | 1K | 2K | 4K |
|---|---|---|---|
| 1:1 | 1024×1024 | 2048×2048 | 2880×2880 |
| 16:9 | 1536×864 | 2048×1152 | 3840×2160 |
| 9:16 | 864×1536 | 1152×2048 | 2160×3840 |

For text generation, auto uses 1:1. For editing, auto matches the closest reference aspect ratio; it does not preserve exact input dimensions. At 2K/4K use PNG/JPEG/WebP references, not GIF/BMP.

## Limits

SVG is unavailable: real test requests returned PNG. It will be exposed after the supplier delivers and passes acceptance. GIF frame counts and pixel sizes are not exposed.

Multiple output images, masks and annotation layers are unavailable. Ineffective upstream controls such as background, moderation and output_compression are not exposed. model pins Flare/Sunburst; do not send version.
