Model IDs: `minimax-h3-image`, `minimax-h3-image-highspeed`.

## Quick start

```bash
curl https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: minimax-h3-image-example-001" \
  -d '{
    "model": "minimax-h3-image",
    "action": "generate",
    "prompt": "A sculptural translucent glass vase with one white calla lily on pale limestone, exquisite daylight, restrained editorial composition, no text.",
    "resolution": "2k",
    "aspect_ratio": "3:4",
    "n": 1,
    "output_format": "png"
}'
```

Poll the original task with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status). Check both `status` and `billing_status`. Output URLs are in `result.images[0].url[]`; download them before expiration. A client timeout does not justify a new submission.

## Accepted parameters

| Parameter | Range |
|---|---|
| `action` | `generate` / `edit`; editing requires references |
| `resolution` | `1k` / `2k` / `4k`; WaveAPI defaults to **2k** |
| `n` | 1–10 |
| `image_urls` | Up to 16; JPG / PNG / WebP / HEIC / HEIF, no GIF |
| `output_format` | `png` (default) / `jpeg` / `webp` |
| `output_compression` | 0–100; default 95, ignored for PNG |
| `prompt_optimizer` | Default true; required for edits, optional for text-only generation |
| `watermark` | Default false |

Exact pixel sizes and separately billed pre-moderation are not yet exposed.

## Billing

Billed on actual modality-specific tokens, **not a fixed price per image**. USD per million tokens:

| Model | Text input | Image input | Image output |
|---|---:|---:|---:|
| H3 Image | 2.4107139 | 1.6071426 | 4.0178574 |
| H3 Image Highspeed | 2.4107139 | 3.2142861 | 8.0357139 |

The quote is a reservation ceiling covering image count, prompt enhancement and references. Completion reconciles actual usage and refunds the difference, capped at the reserved amount.
