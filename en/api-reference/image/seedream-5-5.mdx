Model IDs: `seedream-5.5`.

## Quick start

```bash
curl https://api.qingbo.ai/v1/tasks \
  -H "Authorization: Bearer $WAVE_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: seedream-5.5-example-001" \
  -d '{
    "model": "seedream-5.5",
    "action": "generate",
    "prompt": "A sculptural translucent glass vase with one white calla lily on pale limestone, exquisite daylight, restrained editorial composition, no text.",
    "resolution": "2k",
    "aspect_ratio": "3:4",
    "n": 1,
    "output_format": "png"
}'
```

Poll the original task with [`GET /v1/tasks/{task_id}`](/en/api-reference/task/status). Check both `status` and `billing_status`. Output URLs are in `result.images[0].url[]`; download them before expiration. A client timeout does not justify a new submission.

## Accepted parameters

| Parameter | Range |
|---|---|
| `action` | `generate` / `edit`; editing requires `image_urls` |
| `resolution` | `1k` / `1.5k` / `2k`; default `2k` |
| `n` | 1 only |
| `image_urls` | Up to 10 editing references; every reference is billed |
| `output_format` | `png` (default) / `jpeg` |
| `background` | `auto` / `opaque` / `transparent`; transparency requires PNG |
| `watermark` | Boolean; default false |

Exact pixel sizes, layered output and 3K / 4K are not yet exposed. Upstream launch limits can cause HTTP 429 or queues; reduce concurrency and keep polling already submitted tasks.

## Billing

Per output: 1K / 1.5K **$0.014625**, 2K **$0.02559375**. Add **$0.00585** for every input reference, including the first. Exact sizes that can cross pixel-price tiers are not exposed.
